## 尚待完成

1. **KD、ATR 的 API 與頁面串接**：計算完成不等於使用者已能看到。現有合約保持不變，下一步需同步擴充 `StockData` 與 Python 輸出。
2. **價格品質旗標傳遞**：中台 `stale_adjust=true` 表示除權息還原重抓失敗，但 `backend/api/get_stock_data.py` 尚未將旗標傳給頁面，使用者仍可能看到舊還原價算出的指標。需補明確狀態／暫停判讀。
3. **交叉事件的需求決定**：舊欄位 `latest.macd_crossover` 僅表示兩線位置，不能當事件使用。頁面已避用；若需要金叉／死叉通知，必須比較前後兩根並更新欄位語義。
4. **對照驗收**：目前有數值參考與邊界測試，仍需以相同來源、還原方式、週期和歷史長度，人工對照券商／TradingView。EMA 初始種子與載入長度會影響早期 MACD；完全平盤 RSI 目前可能無有效值，頁面顯示 —。

另外，上櫃 `.TWO` 資料來源支援仍是資料管線待辦，會影響可計算股票範圍。選股評分、交易規則與策略有效性驗證屬後續階段，不應由指標值直接推定已完成。
